# MODULE 1: GOOGLE CHROME (WINDOWS/LINUX) COMPLETE REGISTRY [1, 3, 4] ## 1. Window & Tab Management

* Ctrl + N: Open a new window.
* Ctrl + Shift + N: Open a new window in Incognito mode.
* Ctrl + T: Open a new tab and jump to it.
* Ctrl + Shift + T: Reopen the last closed tab in the order closed (remembers up to 10).
* Ctrl + W (or Ctrl + F4): Close the current active tab or pop-up.
* Ctrl + Shift + W (or Alt + F4): Close the current window entirely.
* Ctrl + Tab (or Ctrl + PageDown): Jump to the next open tab.
* Ctrl + Shift + Tab (or Ctrl + PageUp): Jump to the previous open tab.
* Ctrl + 1 through Ctrl + 8: Switch to a specific tab by its numeric index position.
* Ctrl + 9: Switch to the rightmost tab regardless of total count.
* Alt + Home: Open your home page in the current tab.
* Alt + Left Arrow: Open the previous page from browsing history in the current tab.
* Alt + Right Arrow: Open the next page from browsing history in the current tab. [2, 5, 6, 7, 8]
